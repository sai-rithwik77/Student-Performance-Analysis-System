# Student Performance Analysis System

An analytical system to evaluate and track student academic performance using Python and Streamlit.

## Key Features
- **AI/ML Marks Prediction:** Predicts final student grades using a Random Forest Regressor.
- **Student Performance Dashboard:** Interactive charts and summary statistics powered by Plotly.
- **Early-Warning Alerts:** Automatically flags high-risk and moderate-risk students who need academic support.
- **Personalized Recommendations:** Actionable feedback generated from attendance, study hours, and assignment scores.
- **Model Evaluation:** Real-time performance validation using **MAE**, **RMSE**, and **R²**.
- **Research & Methodology Section:** Built-in overview of the Educational Data Mining (EDM) pipeline and base paper methodology.
- **Downloadable Reports:** One-click export for PDF executive summaries and analyzed CSV files.

## How to Run Locally
1. Install dependencies:
   pip install -r requirements.txt
2. Run the Streamlit app:
   streamlit run app.py
